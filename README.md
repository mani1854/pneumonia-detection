# Pneumonia Detection Using Deep Learning

This repository contains deep learning models and comparative analysis for detecting pneumonia from chest X-ray images.

## Contents
- `ai_pneumonia_detection_model_comparison (1).ipynb`: Jupyter notebook containing data exploration, preprocessing, model architectures, training, and performance comparison.
- `pneumonia_detection_best_model.keras`: Saved weights and architecture for the best-performing trained model.

## Requirements
- Python 3.9+
- TensorFlow / Keras
- NumPy, Pandas, Matplotlib, Seaborn
- Jupyter Notebook / Google Colab
